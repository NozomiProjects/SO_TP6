🛡️ Laboratorio 4: Segmentación y Validación por Hardware

La MMU verifica en cada acceso que el desplazamiento d < Límite (donde bases, límites y desplazamientos se expresan en unidades direccionables / bytes). Si se excede, genera una excepción por violación de límite (Segmentation Fault). Si es válido, calcula DF = Base + d. Experimenta con las direcciones de prueba para verificar accesos válidos y violaciones de límite.
